# Documentation Index

Tài liệu trong `docs/` được chia theo mục đích sử dụng để dễ tìm và dễ bảo trì:

- `docs/adr/`: quyết định kiến trúc và các ADR đã chốt.
- `docs/cron/`: runbook và báo cáo vận hành theo lịch.
- `docs/features/`: tài liệu theo tính năng hoặc domain nghiệp vụ.
- `docs/specs/`: spec kỹ thuật và behavioral contract hiện hành.
- `docs/plans/`: implementation plan theo agent, feature hoặc operation.
- `docs/operations/`: checklist vận hành, deploy, release.
- `docs/roadmaps/`: roadmap sản phẩm và định hướng dài hạn.
- `docs/superpowers/`: artifact nội bộ workflow agent, không là nơi mặc định cho tài liệu chính của repo.
