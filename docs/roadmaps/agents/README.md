# Agent Roadmaps

Roadmap theo agent được đặt ở đây để người đọc đi từ tổng quát đến chi tiết:

1. Chọn agent cần phát triển.
2. Đọc roadmap của agent đó để xác định phase.
3. Từ phase, đi xuống spec và plan tương ứng trong `docs/specs/agents/` và `docs/plans/agents/`.

Roadmap hiện có:

- [Research Agent](research-agent-roadmap.md)
- [Strategist Agent](strategist-agent-roadmap.md)
